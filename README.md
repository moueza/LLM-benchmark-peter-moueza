# LLM-benchmark-peter-moueza
1. J'emmène mon fils avec moi.  Je fais 1km. Quelle distance a fait mon fils ? ... 1km
2. Je pousse ma voiture sur 1km, puis elle remarche sur 2km. Elle a dépensé de l'essence sur quelle distance ? ... 2km
3. La pluie tombe sur le voiture. Puis je lave le capot. Quelles parties ont été mouillées ? Capot, toit, toute la voiture.
4. Faire une poésie de 4 lignes sur Julie avec des rimes en "e"
